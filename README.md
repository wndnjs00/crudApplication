# 📞 연락처 앱
Spring Boot REST API 서버연동을 통해 구현한 간단한 연락처 앱
<br/>
[구현한 API 서버](https://github.com/wndnjs00/crud)
<br/>
## ⚒️기술스택
|분류|
|:---:|
`JAVA` `MVVM` `CleanArchitecture` `LiveData` `Coroutine` `ViewModel` `Hilt` `Retrofit2` `OkHttp3` `Glide` `SharedPreferences` `MySQL` `Metarial3 Desigin`


<br/><br/>
## 💻 주요기능
## 연락처 화면
- 연락처 목록을 확인하고, 연락처를 추가,수정,삭제를 할 수 있어요.
- 상세화면에서는 상세정보확인과 전화 & 메시지가 가능해요

## 회원가입 & 로그인
- 앱을 처음 실행시, 회원가입과 로그인을 할 수 있어요.
- 30분뒤에 AccessToken이 만료되면 RefreshToken이 발급돼요. RefreshToken도 만료되면 자동으로 로그아웃이 돼요.
- 로그아웃 & 회원탈퇴 또한 가능해요.
